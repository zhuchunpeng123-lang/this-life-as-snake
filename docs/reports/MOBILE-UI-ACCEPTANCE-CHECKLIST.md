# 《此生为蛇》移动端 UI 人工验收清单

版本：`mobile-safe-ui-v1-20260808`  
入口：`http://127.0.0.1:4173/index.html`  
预计时长：12–18 分钟

本清单只验收移动端布局、可触达性和桌面零回归；不验收技能强度、波次或战斗平衡。

## 测试准备

1. 使用 Safari 打开入口，并分别在普通浏览器页面与“添加到主屏幕”后测试（后者有不同的安全区/地址栏行为）。
2. 使用横屏进行游戏；先关闭系统旋转锁定。
3. 至少覆盖一台带刘海或灵动岛的 iPhone。建议再覆盖一台小屏 iPhone。
4. 每轮测试从刷新页面开始，进入一局普通游戏，不需要长时间存活。

建议覆盖的视口：

| 优先级 | 设备或等效尺寸（横屏） | 目的 |
| --- | --- | --- |
| P0 | iPhone 14/15：844×390 | 刘海横屏与当前问题的主验收尺寸 |
| P0 | iPhone 14 Pro Max：932×430 | 大屏灵动岛/底部手势区 |
| P1 | iPhone SE：667×375 | 最紧凑横屏高度 |
| P1 | Android 刘海机 | 验证触屏分支不依赖 Safari |
| 回归 | PC：至少 1280×720 | 确认桌面 HUD 未变 |

## A. iPhone 安全区与生命 UI

| 项目 | 触发 | PASS | FAIL | 结果 |
| --- | --- | --- | --- | --- |
| 三颗心满血 | 进入一局，在没有受伤前观察左上生命框 | 三颗心完整位于框内；右侧与边框有清晰空隙；没有被刘海、圆角或浏览器裁切 | 第三颗心贴边、越框、被裁切，或与生命框装饰重叠 | ☐ PASS ☐ FAIL |
| 生命变化 | 主动被敌人碰到 1–2 次，再暂停/继续 | 心形状态切换后仍在同一容器内；无跳位、溢出或闪烁 | 掉血后心形越框、容器尺寸突变、文字压住心形 | ☐ PASS ☐ FAIL |
| 横竖屏往返 | 一局中横屏→竖屏→横屏，然后继续游戏 | 回到横屏后生命框恢复到左上安全区内，三颗心仍完整 | 回切后偏到屏外、出现旧尺寸、心形裁切 | ☐ PASS ☐ FAIL |
| 浏览器/主屏幕差异 | Safari 普通页与“添加到主屏幕”各测试一次 | 两种启动方式都不让生命框贴刘海或屏幕圆角 | 只有其中一种启动方式正常 | ☐ PASS ☐ FAIL |

## B. 左下系统按钮与触控

| 项目 | 触发 | PASS | FAIL | 结果 |
| --- | --- | --- | --- | --- |
| 左下锚定 | 进入一局，观察“暂停 / 全屏”按钮组 | 按钮组位于左下角安全区内；最下按钮与底部手势区有可见间距；整组在屏幕下半区 | 按钮组漂到左侧中部、过度上移、被底部手势区遮挡或贴边 | ☐ PASS ☐ FAIL |
| 最小可触达性 | 单手连续点按“暂停”与“全屏”各 3 次 | 每次都能稳定响应；按钮之间不会误触；不需要精确点到文字中心 | 点按经常无效、误触另一按钮、按钮小到难以点击 | ☐ PASS ☐ FAIL |
| 与摇杆隔离 | 移动摇杆并立即点按暂停，再恢复移动 | 摇杆和系统按钮互不吞触摸；暂停后世界冻结、恢复后输入正常 | 点按钮会拉动摇杆、摇杆区域遮住按钮、恢复后输入失效 | ☐ PASS ☐ FAIL |
| 安全区回流 | 横屏时打开/收起 Safari 地址栏或切换全屏 | 按钮始终重新贴合左下安全区，不出现中部悬浮或屏外裁切 | 地址栏状态改变后位置残留在旧坐标 | ☐ PASS ☐ FAIL |

## C. 全局移动布局稳定性

| 项目 | 触发 | PASS | FAIL | 结果 |
| --- | --- | --- | --- | --- |
| 首局 HUD | 刷新后进入首局，停留 30 秒 | 左上生命、右上阶段、左下系统按钮、右下摇杆各自可见且不重叠 | 任一 HUD 被裁切、彼此压住或与安全区冲突 | ☐ PASS ☐ FAIL |
| 暂停层 | 游戏中点暂停，再关闭暂停层 | 暂停层打开/关闭不改变 HUD 锚点；恢复后系统按钮仍在左下 | 关闭暂停后按钮跳到中间或生命框溢出 | ☐ PASS ☐ FAIL |
| 两局连续运行 | 结束/重开一局，再进入第二局 | 第二局沿用正确的移动端布局，无旧 transform、无累积偏移 | 第二局位置继续漂移、缩放叠加或部分 HUD 消失 | ☐ PASS ☐ FAIL |

## D. 桌面零回归

| 项目 | 触发 | PASS | FAIL | 结果 |
| --- | --- | --- | --- | --- |
| 1280×720 或更大 PC | 打开同一入口进入一局 | 左上生命框和左下系统按钮的桌面位置、尺寸与移动端修复前一致 | 桌面系统按钮被放大、掉到左下，或生命框内容变小/移位 | ☐ PASS ☐ FAIL |
| 窗口缩放 | PC 浏览器从常用尺寸缩到较矮窗口再还原 | 还原后 HUD 回到原桌面布局；无持久偏移或裁切 | 缩放一次后桌面沿用移动端样式 | ☐ PASS ☐ FAIL |

## 结论记录

仅当 P0 项全部通过，才将本移动端 UI 版本视为可接受。若失败，请记录：设备型号、iOS/浏览器版本、启动方式（Safari 或主屏幕）、横屏尺寸、失败项编号，并附一张未裁切截图。
