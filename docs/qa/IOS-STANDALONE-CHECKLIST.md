## A 级：日常快速复验

默认执行，目标控制在 5—10 分钟。测试入口为主屏图标的 standalone 冷启动。

| 步骤 | 操作 | 预期结果 | 实际结果 / 状态 | 备注 |
|---|---|---|---|---|
| A1 | 从主屏图标冷启动游戏。 | 以 standalone 打开，页面正常显示，无白屏或明显布局错乱。 |  |  |
| A2 | 点击开始并进行第一次用户手势。 | BGM 正常开始播放。 |  |  |
| A3 | 触发一次战斗音效。 | 战斗音效正常播放，BGM 不被错误永久打断。 |  |  |
| A4 | 暂停后继续游戏。 | 暂停和继续正常；继续后声音恢复。 |  |  |
| A5 | 切到后台，再返回游戏。 | 游戏可恢复；返回后 BGM 和音效正常。 |  |  |
| A6 | 死亡并重新开始一次。 | 死亡流程和重新开始正常；新一局声音仍正常。 |  |  |

### A 级判定

- A1—A6 全部通过：记录“iOS standalone 核心音频主流程通过”。
- 任一步失败：记录“ A 级失败”，不得写成“已验收通过”；根据失败类型决定是否升级 B 级或 C 级。

## B 级：音频或启动代码改动后

只有修改以下内容时执行：

- `snake55/10_audio.js`；
- 开始游戏流程；
- 暂停/恢复流程；
- 页面前后台切换逻辑；
- iOS 音频解锁逻辑。

| 步骤 | 操作 | 预期结果 | 实际结果 / 状态 | 备注 |
|---|---|---|---|---|
| B1 | 在 Safari 普通页面打开并开始游戏。 | 页面加载正常；首次用户手势后音频可用。 |  |  |
| B2 | 从当前版本重新打开主屏 standalone 并冷启动。 | standalone 页面正常启动；没有白屏或旧页面异常。 |  |  |
| B3 | 完成首次用户手势解锁音频。 | BGM 和可触发的音效均可用。 |  |  |
| B4 | 暂停后继续。 | 暂停/恢复状态正确；声音按预期停止并恢复。 |  |  |
| B5 | 切后台后返回。 | 页面可恢复；音频不会永久无声或重复叠播。 |  |  |

B 级通过后，只能说明本次改动对应的启动和音频路径通过，不能替代发布前 C 级检查。

## C 级：发布前或故障排查

以下内容不列为日常必测，仅在发布前，或 A/B 级失败、需要诊断时执行：

- 删除并重新添加主屏图标；
- 锁屏再解锁；
- 离线启动；
- 清理网站缓存后启动；
- 多设备或不同 iOS 版本对照；
- 长时间后台后恢复；
- 观察 `AudioContext` 状态和浏览器控制台；
- 使用详细失败复现模板。
