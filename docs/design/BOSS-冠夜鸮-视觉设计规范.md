# 《此生为蛇》BOSS「冠夜鸮」视觉设计规范

版本：v0.2
状态：第一阶段生产规范

## 1. 文档职责

本文件只负责冠夜鸮的：

* 角色视觉DNA
* 色彩关系
* Master Pose
* PNG与Canvas边界
* Phase 2表现
* 动画资源升级条件

世界观以 `WORLD-BIBLE.md` 为唯一真理源。

## 2. 定位

**冠夜鸮——夜庭终境守夜者 / 顶层夜行掠食者。**

不是其他敌人的国王或首领。

目标体验：

**待机略萌，进入攻击状态后突然危险。**

## 3. 第一印象优先级

1. 一眼认出猫头鹰；
2. 一眼看出Boss层级；
3. Q版、圆润；
4. 天然冠羽形成独特轮廓；
5. Charge/Release产生明显掠食压迫感；
6. 在深色Canvas背景和密集战斗中保持可读。

## 4. 视觉DNA

必须保持：

* 大头圆身
* 正面偏轻微俯视
* 清晰猫头鹰面盘
* 双眼承担主要表情
* Idle短翼收拢
* 3～5片天然冠状头羽/耳羽
* 简洁可辨识的喙
* 大色块、低细节密度
* 圆润与危险并存

“冠”必须属于身体结构。

允许少量暗金/黄铜/古铜色角质或硬质羽片。

禁止：

* 人类皇冠
* 皇冠悬浮
* 珠宝装饰
* 写实密集羽毛
* 机械装甲
* 血肉恐怖
* 复杂挂件

## 5. 色彩

环境基准：`#11162a`

关系：

* 深轮廓：深靛紫/近黑紫
* 暗部：暗紫
* 主体：中深紫
* 危险：品红/玫红
* 战斗高光：近白紫
* 冠羽：暗金/黄铜/古铜/低饱和脏金

原则：

品红和近白紫负责战斗信息。

暗金只负责身份，不使用亮奖励黄，不发金币式强黄光。

最终Hex需根据实际游戏截图校正。

## 6. 第一阶段资源

严格按顺序：

1. `enemy_boss_idle_master.png`
2. `enemy_boss_charge_master.png`
3. `enemy_boss_release_master.png`

共同要求：

* 1024×1024
* 透明背景
* 中心锚点
* 正面偏轻微俯视
* 主体约占75%～80%
* 无场景
* 无文字
* 无程序VFX
* 三姿势角色结构高度一致

不得批量一次生成。

## 7. Idle

Idle是角色母版。

必须：

* 大头圆身
* 短翼收拢
* 冠羽清晰但不是皇冠
* 一眼认出猫头鹰
* 略萌但不显无害
* 缩小后面盘、眼睛、喙、冠羽仍可读

Idle未批准，不进入下一阶段。

## 8. Charge

必须基于已批准Idle继续制作。

变化：

* 身体明显鼓气
* 双翼展开约30%～50%
* 头部稍压低
* 眼神危险
* 横向轮廓明显增加
* 眼部/胸部保留程序高光区域

不得重新随机设计另一只猫头鹰。

## 9. Release

继续继承同一角色DNA。

变化：

* 双翼大幅展开
* 身体向前
* 攻击表情
* 三姿势中横向轮廓最强
* 短时间呈现顶层捕食者压迫感

不得把能量束、冲击波、粒子等画死进PNG。

## 10. Canvas与PNG边界

PNG负责：

* 身体
* 姿势
* 表情
* 固有色
* 基础材质
* 冠羽

Canvas负责：

* 呼吸
* 上下浮动
* squash/stretch
* 眼睛分级发光
* 羽毛聚拢
* 蓄力环
* 冲击环
* 羽毛爆散
* 后坐
* Hit Flash
* Phase 2能量
* Death dissolve

原则：

**PNG决定角色是什么；程序决定战斗能量如何变化。**

## 11. Phase 2

第一版不制作完全不同的新造型。

首选：

* 品红轮廓增强
* 近白紫眼睛/胸部核心
* 稀疏暗紫羽雾

禁止同时堆满强皇冠光、全身变色、大光环、高密烟雾和大量粒子。

目标是“阶段升级清楚”，不是“特效最多”。

## 12. Sprite Sheet

当前不直接制作8帧。

先实机验证：

Idle → Charge → Release → Recover

结合程序动画。

只有出现：

* 明显PPT换图感
* Charge体积跳变
* Release展翼不连续
* Recover瞬移感
* 程序插值解决不了轮廓断层

才升级为8帧：

1. Idle
2. Begin Inhale
3. Inflate
4. Max Charge
5. Wing Open
6. Release
7. Recoil
8. Recover
