《此生为蛇》UI图标风格规范 v0.1

一、目标
本规范只约束游戏内技能图标 / Combo图标。
目标不是做“插画”，而是做“正式游戏UI图标”。

二、总方向
世界观基准：
- 寓言化夜色生态 / 暗色霓虹生命世界
- 可爱与危险并存
- 清晰、爽快、可读
- 有生命感，但不能恶心、黏腻、诡异

三、必须遵守
1. 图标优先是“技能符号”，不是“器官插画”
2. 缩小到 48px 左右仍能快速辨认
3. 强轮廓、大色块、低细节
4. 统一描边粗细、统一发光强度、统一安全边距
5. 每个图标最多 1 个主主体 + 1 个辅助元素
6. 内部层次控制在 2~3 层
7. 透明背景，正方形画布，视觉中心一致
8. 图标整体要比怪物/Boss更干净、更抽象、更功能化

四、明确禁止
1. 明显心脏感、胚胎感、内脏感、器官感
2. 孢囊、肉瘤、黏液、血肉组织感过强
3. 恐怖、诡异、恶心方向
4. 纹理过多、细节过满、缩小后发糊
5. Combo 图标把所有元素硬堆在一起

五、画布与占比
- 统一 512×512
- 透明背景
- 主体占画布约 70%~80%
- 四周保留统一安全边距
- 图标实际视觉重心尽量一致

六、颜色方向
- fire：橙红 / 金黄
- ice：冰蓝 / 浅青
- bolt：黄绿 / 荧光绿
- shield：薄荷绿 / 青绿
- lightning：蓝紫 / 电蓝

七、Combo原则
Combo 是“两个基础技能的融合结果”，不是完全陌生的新东西。
必须一眼看出来源关系，但仍保持简洁可读。

八、最终审查标准
- 是否一眼看出技能类型
- 是否缩小后仍清晰
- 是否统一
- 是否干净
- 是否有不适的器官/心脏/黏腻感
未通过任一项，不进入正式接入。
