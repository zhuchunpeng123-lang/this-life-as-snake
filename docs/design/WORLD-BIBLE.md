# 《此生为蛇》WORLD-BIBLE

版本：v1.0
状态：当前世界观真理源

## 1. 世界一句话

《此生为蛇》发生在一片暂称“夜庭”的寓言化永夜生境。

玩家不是救世英雄，只是一条刚出生的蛇。

每一局都是它的一生：

**出生 → 吞噬 → 成长 → 异变 → 贪婪 → 面对更危险的生命 → 死亡或跨越终点 → 留下这一生的记忆。**

## 2. 核心主题

世界观服务三个主题：

**生长**：蛇不断吞噬世界，将外界转化为自己的身体。

**贪婪**：更多身体和力量让蛇更强，也让这一生更加激进和危险。

**记忆**：战斗时身体首先是战力；生命结束后，经历重新成为对这一条蛇生的回望。

核心情绪：

**生前求强，死后回望。**

## 3. 夜庭

“夜庭”目前是工作名。

它不是现实森林，也不是动物王国、赛博城市或传统奇幻世界，而是一片具有寓言性质的夜色生命世界。

世界的视觉语气摘要是：**明快的夜色幻想生态**。

体验优先级依次为：**清晰 / 可爱 / 爽快**，其次是**夜色 / 神秘 / 霓虹**，最后才是**危险 / 异变**。具体视觉执行规则由 `ART-BIBLE.md` 管理，本文件不展开为美术规范。

允许：

* 深色环境
* 霓虹生命光
* Q版动物
* 非现实生命能量
* 稍微怪诞的生物形态

当前不锁定夜庭究竟是真实世界、生命循环空间，还是“一生”的寓言表达。

## 4. 玩家蛇

玩家是一条普通新生蛇，不是被选中的英雄。

它没有固定职业。

每一局的Build代表：

**同一种生命走出的不同人生。**

火、冰、电、护盾等构筑，是这一条蛇在本局逐渐形成的生命特征。

## 5. 生命残光

夜庭中的生命和特殊物质会留下可被吞噬的“生命残光”。

“生命残光”目前是工作概念，用于统一解释：

* 食物
* 成长
* 蛇身
* 技能获得
* 部分记忆表现

蛇吞噬残光后继续生长。

生命结束后，这些经历又成为这一条蛇的记忆。

## 6. 生命异变

火焰、寒冰、闪电、护盾等能力不是传统魔法。

它们是：

**吞噬特殊生命残光以后形成的生命异变。**

技能升级代表异变强化。

Combo可以解释为多种生命异变在同一身体中形成新的共鸣。

因此技能视觉优先体现生命、能量、异变和共鸣，而不是传统法师施法。

## 7. 敌人

普通敌人不是一个王国、军队或统一阵营。

它们是夜庭中具有不同生存方式和危险等级的生命。

它们可以表达不同本能，例如：

* 迟缓占据
* 追逐
* 冲撞
* 防御
* 捕食

敌人真正统一的是同一个世界的视觉语言，而不是政治关系。

## 8. Boss

Boss不是传统魔王。

Boss代表：

**一条生命成长到足够远以后必须面对的最高级生存门槛。**

当前Boss“冠夜鸮”定位为：

**夜庭的终境守夜者 / 顶层夜行掠食者。**

它不是其他敌人的国王。

击败它意味着这条蛇跨过了这一生目前最大的生存门槛。

## 9. 冠夜鸮摘要

冠夜鸮是一只具有天然冠羽结构的巨大夜鸮。

平时圆润、Q版、略萌而警觉。

进入攻击状态后：

* 眼神收紧
* 身体鼓起
* 双翼展开
* 危险生命能量增强

“冠”来自天然冠羽，不是人类皇冠。

具体造型由 `BOSS-冠夜鸮-视觉设计规范.md` 管理。

## 10. 生与死

死亡不是单纯失败。

战斗结束以后，玩家重新看到：

* 这一生走了多远
* 长成什么样
* 获得什么力量
* 做过什么选择
* 如何结束

因此体验应从：

**高密度战斗、生存、追求力量**

逐渐切换到：

**安静、回望、总结这一生。**

通关也是一条蛇生的结束，只是结局不同。

## 11. 视觉世界规则

保持：

* Q版
* 圆润
* 暗色夜景
* 霓虹生命感
* 可爱与危险并存
* 大轮廓
* Canvas缩放后高辨识度

生命感、异变和生态奇异感应保持寓言化、明快和可读，不得自行延伸为心脏、内脏、胚胎、肉瘤、腐败、脓液等生物恐怖方向。

避免：

* 写实动物
* 恐怖血肉
* 重度赛博机械
* 动物王国政治体系
* 传统剑与魔法
* 大量复杂装备
* 依赖细小纹理辨识角色

## 12. 色彩语义

当前原则：

* 玩家：鲜绿/青绿
* 普通敌人：红/紫
* Boss：更深紫与品红
* 奖励/价值：金/黄/绿
* 环境：深蓝/灰/近黑
* 强战斗能量：近白高光

具体Hex由后续ART-BIBLE或专项视觉规范管理。
