# 《此生为蛇》技能与 Combo 表现规范

版本：v1.2
性质：ChatGPT 美术窗口与 Codex 共用的设计真理源

## 1. 目标优先级

1. 功能关系清楚；
2. Lv1 即可感知；
3. Lv5 成长明确；
4. 基础技能与 Combo 身份分离；
5. 与夜庭世界协调；
6. 怪群、桌面和手机中均可读；
7. 性能稳定；
8. 最后才是华丽程度。

效果必须在真实游戏尺寸、移动目标、遮挡和高密度战斗中成立，不能只在大图或静态概念图中成立。

## 2. 技能身份六维

每个技能必须冻结：

- 颜色；
- 核心形态；
- 触发与动作节奏；
- 发射来源；
- 命中反馈；
- 音频身份。

基础技能与 Combo 不得只换色。Combo 同等级至少在动作、视觉重量、命中和声音中的三项明显强于基础技能。

## 3. PNG 与程序 VFX 分工

### PNG 负责

- 稳定轮廓；
- 视角；
- 材质；
- 光学中心；
- 世界实体身份。

### 程序 VFX 负责

- 动态方向；
- 传播；
- 呼吸；
- 充能；
- 释放；
- 束线；
- 拖尾；
- 命中；
- 等级成长。

世界实体技能默认优先采用：

> 简单完整 PNG + 程序动作/VFX

复杂 PNG 不等于游戏内效果更好。视角、实际尺寸、图层和动作不匹配时，精致素材反而会降低整体品质。

## 4. 素材制作与预览顺序

1. 先制作最终透明独立素材；
2. 检查 Alpha BBox、optical center、anchor 和真实小尺寸；
3. 再放入真实游戏截图制作运行预览；
4. 预览只使用当前 Canvas 能实现的光束、节点、环和粒子；
5. 同时检查空场、少怪、怪群、移动目标、Lv1、Lv5、桌面和手机；
6. 对抗性审查通过后再接代码。

## 5. 图层

同一束线的：

- 外层；
- 主线；
- 白芯；
- 命中节点；

默认属于一个完整表现单元，不得无目的拆到怪物上下两层。

推荐顺序：

```text
地面范围与阴影
→ 世界实体
→ 怪物与蛇
→ 关键技能完整表现
→ 伤害数字
→ UI
```

需要持续可读的悬浮阵地技能可以整体放在最高战斗层。不要让 PNG 主体、主线和核心被分散到不同层后产生“被淹没”或局部粗细不一致。

## 6. 移动目标

短时束线可在事件数据中附带目标 ID，并在 VFX 生命周期内读取目标当前坐标。

必须保证：

- 只更新视觉端点；
- 不重新索敌；
- 不重复伤害；
- 目标死亡后保留最后坐标或安全失效。

## 7. 路径

- 稳定能量炮使用近直线；
- 闪电链在真实目标节点之间跳跃；
- 转折发生在目标处；
- 关节电核解释转折；
- 不使用每帧随机路径；
- 不把闪电画成软管或另一条蛇。

## 8. 等级成长

不能只改线宽。至少选择三项：

- 主线宽度；
- 外层宽度和透明度；
- 白芯；
- 节点大小；
- 传播、蓄力或回弹；
- 命中反馈；
- 音频层次。

Lv1 必须完整可见，不能依赖目标多才有存在感。Lv5 应形成高潮，但不通过永久巨型实体或长时间全屏光柱制造强度。

## 9. 受击来源

- 普通投射物：颗粒、音效、轻击退或短停顿；
- 闪电：落点电核和短环；
- 电磁或爆炸：短促冷色薄染、冲击环或较重命中；
- DOT：聚合文字和持续状态。

禁止“所有非 DOT 伤害统一整图白闪”。

## 10. 性能

每个效果必须固定：

- 最大目标数；
- 最大节点和粒子数；
- 生命周期；
- 束线层数；
- 高密度降级项。

降级顺序：

1. 装饰粒子；
2. 次级外环；
3. 残影和辐条；
4. 保留主体、主线、核心和命中点。

默认避免：

- `shadowBlur`
- `ctx.filter`
- 大范围 `lighter`
- 每帧随机折线
- 无上限粒子雨

## 11. 对抗性审查

交付前必须检查：

- 是否像贴纸；
- 是否在怪群中被淹没；
- 是否局部粗细不一致；
- Lv1 是否看不见；
- Lv5 是否只有简单放大；
- 基础技能和 Combo 是否同质；
- 移动目标是否漂移；
- 高密度是否删除核心身份；
- 预览是否代码可实现；
- 是否误改 Gameplay；
- 是否更新缓存戳。

## 12. 电系样板结论

### 基础闪电

- 冷蓝白；
- 真实目标节点之间逐段跳跃；
- 关节电核解释转折；
- 完整束线统一位于怪物之上；
- 视觉端点短时跟随目标 ID；
- Lv1 清晰，Lv5 明显加强。

### 电磁炮台

- 夜庭生命晶环 PNG；
- 紫色主束 + 青白核心；
- 部署、呼吸、充能、齐射、回弹；
- 主体和关键束线位于最高战斗层；
- 同等级强于基础闪电；
- 炮台主体大小适度，成长主要由束线、动作和命中承担。
