# 《此生为蛇》美术资源规范

版本：v1.1
状态：当前美术资源接入规范

## 1. 适用范围

本文件规定 PNG/静态美术资源进入游戏前的资产契约、命名、校准和验收方式。它不镜像运行时半径、缩放、HUD 尺寸、伤害、碰撞、波次或其他 CONFIG 数值；运行时事实以代码和 `snake55/02_config.js` 为准。

## 2. 通用资源契约

- 默认使用带透明 Alpha 的 PNG；不把背景色烘焙进角色、图标或 VFX 资源。
- 命名应表达对象、状态和用途，例如 `enemy_wanderer.png`、`enemy_boss_idle_v1.png`、`skill_fire.png`。
- 每个资源接入前记录并核对：源画布、Alpha Bounding Box、主体占比、optical center、anchor/pivot、safe area 和透明边缘。
- 源画布相同不代表实际视觉重量相同；显示大小必须以主体比例、视觉中心和场景层级校准。
- 透明边缘不得残留无关杂色、色边或裁切造成的主体缺口。

## 3. 资产类别

### 3.1 角色、敌人和 Boss

主体应保持清晰轮廓、稳定视觉中心和可辨识姿态。多状态资源切换时，头部、核心躯干和主要攻击方向应保持连续；动作外扩不得破坏既有碰撞与身份层级。

### 3.2 UI 与图标

图标必须在独立 cell 内居中，等级、状态、徽标和文字使用独立布局层。PNG 画布尺寸不得直接决定 UI 视觉重量；接入时校准主体 BBox、padding、scale 和文字间距。

### 3.3 技能、Combo 与 VFX 资源

PNG 负责实体身份、材质和基础形状；Canvas、粒子和程序 VFX 负责方向束线、命中、范围、动态状态和时序。静态资源不得烘焙会与程序层重复的目标方向、命中结果或大范围动态粒子。

### 3.4 背景与装饰

背景服务于战斗可读性和层级，不得压过蛇头、敌人预警、掉落物和命中反馈。装饰资源应标明用途和所属层，不作为 gameplay 状态来源。

## 4. 接入边界

- 资源身份和材质由 PNG/静态资源表达；运行时位置、时间、缩放和状态由对应表现模块控制。
- 资源加载入口由 `snake55/02_config.js`、`11_render.js`、`12_ui.js` 或对应系统负责；不得借资源替换改动碰撞、伤害、波次或输入语义。
- 视觉调试应在真实战场中检查缩放、遮挡、跟随、命中可读性和移动端裁切。
- 缺失资源必须保留可用 fallback，不得因单个 PNG 失败使角色或 UI 消失。

## 5. 资源验收清单

接入前至少确认：

1. 文件格式、Alpha 和命名正确；
2. 主体 BBox、视觉中心、anchor/pivot 和 safe area 可解释；
3. 在目标场景中与同类对象的视觉重量一致；
4. 关键轮廓、预警、命中反馈和文字没有被遮挡；
5. 静态资源与程序 VFX 的职责没有重复；
6. 缺失、加载失败和低密度/高密度场景仍有合理表现；
7. 相关源码检查通过，剩余视觉结论明确交由人工或显式视觉验收。

## 6. 当前接入地图

- 玩家、敌人和 Boss：`snake55/11_render.js` 与对应资源入口。
- 技能、Combo 和粒子：`snake55/05_particle.js`、`snake55/08_skill.js`、`snake55/11_render.js`。
- HUD 与系统界面：`snake55/12_ui.js` 及 `CONFIG.STYLE.UI`。
- 具体资源清单、当前 WIP 和发布状态以实时工作树、代码和 `docs/STATUS.md` 为准。
