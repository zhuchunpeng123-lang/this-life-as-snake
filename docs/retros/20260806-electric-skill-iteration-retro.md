# 电系技能表现专项复盘

日期：2026-08-06
范围：基础闪电链、电磁炮台 Combo、怪物受击、电系音频与 AI 交付流程

## 最终成果

- 基础闪电与电磁炮台视觉身份分离；
- 电磁炮台形成部署、呼吸、充能、齐射、回弹；
- 闪电链完成路径、粗细、等级成长、图层统一和目标跟随；
- 修复飞镖误触发整图闪白；
- 闪电与电磁音频身份分离；
- 发现并修复专属音效与通用命中音双重触发；
- 建立 PowerShell 精简基线导出和精确补丁交接流程。

## 可复用经验

1. 先定义颜色、形态、节奏、来源、命中和声音，再做效果。
2. 世界实体优先“简单完整 PNG + 程序动作/VFX”。
3. 同一束线的外层、主线、白芯和节点必须按完整效果审查图层。
4. 移动目标需要目标 ID 做纯视觉跟随。
5. Lv1 必须完整可见，Lv5 不能只增加线宽。
6. 受击必须按来源区分，不能全伤害统一白闪。
7. 一个攻击来源只能有一个主要音效所有者。
8. 专属音效必须审查 `enemy:hit`、专属 fx 与死亡音的完整事件链。
9. 高密度降级先删装饰，不能删掉技能身份核心。
10. 用户实机验收不能被静态检查替代。

## 主要失败

- 精致但视角错误的 PNG；
- 低细节被误做成半成品；
- 高密度模式删除了关键充能；
- 同一束线分层导致局部粗细不一致；
- 保存旧坐标导致移动目标命中漂移；
- 旧基线导致补丁多次失效；
- 专属闪电音与通用命中音重复触发；
- 闪电与电磁共用 gate 导致同一级音色不稳定。

## 冻结点

电系视觉和音频通过最终实机验收后：

- 不再改变颜色身份和炮台造型；
- 不再改变束线图层和 Gameplay；
- 不继续无上限增加粒子；
- 全局伤害数字、DOT、Debuff、暴击另开专项；
- 数值与单局节奏在美术冻结后处理。
