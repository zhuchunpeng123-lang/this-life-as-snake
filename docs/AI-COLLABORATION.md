# 《此生为蛇》AI 协作规范

## 1. 总原则

- 用户决定产品定位、世界观、核心玩法、平衡方向和重大审美取舍。
- AI 在用户授权范围内负责分析、创作、实现、验证和交付。分工按当前工具、能力和任务效率决定，不因“总控、专项、Codex”等名称人为禁用可用能力。
- 聊天记录不是项目真理源；需要长期生效的结论写入对应正式文档。

## 2. 执行权限

- 用户明确要求执行，即视为对所述低风险范围的授权。
- 授权在整个任务范围内持续有效。AI 可自主选择实现路径、处理必要伴随修改、运行验证、自主修正并完成 Git 闭环，无需逐步重复确认。
- 高风险暂停条件以 `AGENTS.md` 为准，其他流程、复盘和历史文档不得扩大暂停范围。
- 产品方向、核心玩法、平衡方向、已锁定视觉 DNA 和高风险工程修改仍由用户决定。

## 3. 工作方式

- 默认流程：内部计划与自审 → 执行 → 验证 → 必要修正 → 交付。
- 计划不替代完整需求，也不自动要求创建计划文件或等待确认。
- 遇到不确定信息，先检查代码、文档、测试和现有模式；只有存在无法推断的实质选择时才询问用户。
- 不设置固定自主修正轮数。在范围、风险和证据允许时继续收敛；验证通过或无法安全继续时结束。

## 3.1 视觉任务分级

### A. 默认人工验收

对于用户可以快速实机确认的简单视觉任务，Codex 只完成代码、检查和 Commit，由用户实机验收，不自动截图。

### B. 概念预演

当新 UI、新技能、新角色或新素材的视觉方向未确认时，优先使用 ImageGen 生成 1～3 个可审查概念方向或关键帧；用户选定方向后再开始代码和资源接入。概念预演不等于最终游戏内验收。

### C. 完整视觉验收

只有用户显式调用 `$visual-review` 时，才运行浏览器截图、视觉自审和一次自主修正；证据不足时不得宣称视觉验收通过。

## 4. 真理源

- `AGENTS.md`：工程权限和硬规则。
- `CHATGPT-CONTROL.md`：总控窗口的当前项目摘要、分流规则和优先级入口。
- `PROJECT-BRIEF.md`、`PROJECT-STATUS.md`、`DEBT.md`：项目事实、当前状态和开放问题。
- GDD、`docs/design/`：设计、世界观和视觉规范。
- `snake55/02_config.js`：运行时数值入口。
- `RETRO`、`HANDOFF`、`RELEASE`、`archive`：历史证据，不定义当前执行权限。

发生冲突时按以下优先级处理：

用户当前明确指令 → `AGENTS.md` → 当前专项真理源 → 当前状态文档 → 历史资料。

总控窗口先读 `CHATGPT-CONTROL.md`，再按任务需要回读状态、债务、计划、GDD 或设计真理源；总控摘要不替代专项真理源。

## 5. 上下文与输出

- 只读取当前任务必要的规则、源码和专项真理源，不默认扫描全部历史资料。
- 默认输出结论、实际改动、验证结果和必要风险。
- 不为简单任务创建无价值计划、重复分析或额外文档。
