# 《此生为蛇》项目定义

## 定位

《此生为蛇》是一个原生 JavaScript + Canvas 的网页游戏，将贪吃蛇、Roguelike 割草和 AI 叙事结算组合为单人短局体验。

玩家操控一条持续前进的蛇，通过吞噬增长、自动技能和 Combo 清理敌潮，并在终点挑战 Boss。蛇身既是成长记录，也是技能与叙事记忆的载体；死亡或通关后，战斗履历进入结算叙事。

## 核心体验

- 越贪越强，也越容易把唯一命门蛇头置于危险中。
- 秒级战斗提供掌控、成长和割草反馈；Session 级结算提供回味与再开一局动机。
- 玩法先保证可读、可操作、可验证，再追求更密集的表现和更丰富的内容。
- 设计意图可以描述目标体验，但不代替当前代码状态、运行时数值或发布验收。

## 稳定产品决定

- 《此生为蛇》是基于 HTML5 Canvas 的 Web 游戏，同时覆盖桌面浏览器与移动端/iOS Safari/standalone。不同终端可以采用不同输入与布局适配，但共享同一核心玩法语义。
- 蛇头是主要生存命门；蛇身、技能、Combo、敌潮和 Boss 共同构成战斗压力。
- 技能沿蛇身或其战斗位置自动工作，升级以构筑选择和可感知反馈为主。
- 视觉、美术、音频应服务战斗信息、身份识别和情绪节奏；具体资产与实现可随专项验收迭代。
- 世界观、叙事和角色身份以 `docs/design/WORLD-BIBLE.md`、GDD 及对应领域文档为设计意图来源。
