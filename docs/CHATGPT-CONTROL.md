# 《此生为蛇》ChatGPT 总控入口

> 生成基线：2026-08-04，审计时 HEAD 为 `fec168a`，工作区为 `main`。本文件是总控摘要，不替代 `AGENTS.md`、当前状态、CONFIG、GDD 或专项设计真理源。

## 1. 项目定位与当前目标

《此生为蛇》是原生 JavaScript + Canvas + Web Audio 的网页游戏，把 360° 不停前进的贪吃蛇、Roguelike 构筑、波次战斗和“死亡后写出一条蛇的一生”结合起来。核心体验是：蛇身越长，技能和记忆越丰富；贪婪带来更强输出，也让唯一命门蛇头更容易暴露。当前目标不是继续堆功能，而是把 5.5 内部交接基线打磨成可稳定演示、可复验、可继续迭代的垂直切片；它仍不是 GA 发布版。

## 2. 当前可玩能力

当前提交基线已具备蛇头移动、成长、碰撞、波次、敌人、技能自动释放、3 选 1 构筑、Combo、Boss、HUD、移动端横屏与摇杆、Web Audio、死亡结算和 AI 蛇生模板等主链路。音频已完成 BGM、战斗 SFX、UI 反馈分轨以及暂停、死亡、Boss 结算状态处理；iOS Safari/standalone 在关闭系统静音开关且媒体音量正常时已完成基础对照，但完整 standalone 主流程仍按 A/B/C 清单待记录，静音开关打开无声按平台限制处理。VFX 方面，火焰回到可读基线，Boss 战斗表现已降噪，燃烧/减速等元素状态采用头顶图标并完成并排对齐。

## 3. 已冻结决策

- 360° 自由转向、恒速前进、蛇身与自身穿过；蛇头是唯一命门，蛇身不因敌人接触掉血。
- 蛇身同时承担长度、技能几何平台和记忆载体；食物/记忆是同一拾取资源。
- 过程追求清晰、可爱、爽快；结算从高密度战斗切换到安静回望。
- 世界观为“夜庭”工作设定；玩家是普通新生蛇；火、冰、电、护盾等是生命异变，不是传统职业魔法。
- 全局视觉采用明快夜色幻想生态、Q 版圆润大轮廓、高辨识度；禁止自行扩展为血肉恐怖、重机械赛博或传统王国体系。
- 冠夜鸮是顶层夜行掠食者/终境守夜者，天然冠羽属于身体结构，不是人类皇冠。
- 技术架构保持无构建、固定脚本顺序、无 import/export、window 全局；运行时数值只认 `snake55/02_config.js`。

## 6. ChatGPT、Codex 与任务分流

ChatGPT 总控负责维护需求池、优先级、产品取舍、风险、验收标准和真理源冲突裁定；Codex 负责在授权范围内读取代码、实现、验证、提交和交付。普通任务直接读 `AGENTS.md`、相关源码和专项真理源；只有跨模块、高风险、长期跟踪或用户要求时才建立正式计划。用户明确要求计划、使用 Plan 模式或未授权执行时，不改文件；高风险边界仍需确认。

视觉任务分三级：用户能快速实机判断的简单 UI/素材替换默认由 Codex 完成代码检查和 Commit，用户人工验收，不自动截图；新 UI、技能、角色或素材方向未定时，先用 ImageGen 做 1～3 个概念方向/关键帧，用户选定后再接入；只有用户显式写出 `$visual-review`，才运行浏览器截图、直接读取证据、自审并最多自主修正一次。证据不足不得宣称视觉通过。
