# 《此生为蛇》AUDIO-BIBLE

版本：v1.0（Phase 1）
状态：当前全局音频真理源

## 1. 总声音定位

整体声音定位：**明快的夜色幻想生态 / 夜庭生命幻想音色**。

优先级：**清晰、好听、爽快 > 夜色、神秘、生命感 > 危险、异变、力量感**。

声音必须服务《WORLD-BIBLE》的“出生 → 成长 → 异变 → 贪婪 → 死亡/通关 → 回望”。禁止把项目做成重赛博、8-bit 街机、传统剑与魔法或恐怖血肉风格。

## 2. 四个声音母题

- **夜庭**：柔和空气、深夜空间、克制余响。
- **生命**：呼吸、木质、果实、甲壳、圆润有机触感。
- **异变**：晶体、冰裂、电弧、火焰、非机械生命能量。
- **成长**：从轻、疏、窄逐步变得厚、密、宽；不能只靠提高音量。

## 3. 混音主次

任何时刻必须存在“主角声音”。推荐语义优先级：

1. 玩家致命/受伤、Boss 关键警告。
2. Combo、Boss 核心动作。
3. 当前主要基础技能。
4. 精英死亡、关键命中。
5. 普通命中、普通死亡。
6. 食物、环境碎响、次要 UI。

高优先级声音出现时，低优先级声音应通过 Voice Budget、聚合、节流、duck 让位，而不是所有声音同时变响。

## 4. Bus 语义

运行时 SFX 使用：`skill / combo / player / impact / death / boss`，UI 与 Music 独立。

- `skill`：基础技能身份。
- `combo`：Combo 和组合武器，优先于基础技能。
- `player`：玩家受伤、碰撞等自身反馈。
- `impact`：普通敌人命中。
- `death`：普通/精英敌人死亡。
- `boss`：Boss 阶段、警告和关键动作。

## 5. BGM 成长原则

BGM 使用 **同主题、不同编曲状态**，不是“一个底层从出生一直叠到 Boss”，也不是五首互不相关的歌。

核心情绪曲线：**生命苏醒 → 开心成长 → 主动迎战 → 强者高潮 → Boss 决战**。

- Stage 1「新生」：明亮夜庭、轻盈好奇。中高音域空气与晶体/生命弹拨为主，不持续铺低频 Bass，不做阴沉氛围。
- Stage 2「成长」：同一生命主题增加轻根音、短促弹拨和微弱律动，表达“我开始变强”。
- Stage 3「迎战」：进入明确 Groove，加入有限 Kick / Snare / Hat 与推进 Bass；情绪是“来啊”，不是恐惧。
- Stage 4「强者」：更快节奏、更高旋律、更密 Bass 与打击，形成 Power Fantasy，表达“我已经很强”。
- Stage 5「Boss」：继承 Stage 4 的昂扬与主题，只增加重量和张力，不能突然变成黑暗恐怖音乐。

技术规则：

1. 五阶段使用同一个 transport 和同一组主题材料，但每个阶段是**独立 arrangement**。
2. 阶段切换量化到下一小节；旧 arrangement 必须淡出，新 arrangement 接管，禁止旧阶段音乐长期留在下面。
3. 共享的是主题、和声亲缘与音色 DNA，不是持续叠加的旧声部。
4. Stage 1 禁止持续低沉 Bass；Pad 必须留呼吸空隙，避免“死气沉沉”和双层错觉。
5. 后期通过节奏、音域、配器密度和力度递进制造热血，不仅靠整体增益变大。
6. 如果程序化版本仍无法达到“好听”的验收线，停止继续微调 oscillator，直接升级为预制 Music Stem/Loop；Web Audio 只保留 transport、transition 与 mix。

## 6. 技能声音原则

每个基础技能必须能盲听区分；Combo 比基础技能高一个重量等级。

Phase 2 冻结最终技能声音前，当前 Phase 1 只建立混音与素材接入底座，不擅自把现有技能最终定型。

建议身份：火=呼/燃/噼啪；冰=咔/叮/结晶；飞镖=咻/切风/硬质命中；护盾=咚/晶体/共鸣；闪电=啪/啪/啪啪啪电弧。

## 7. 素材路线

允许并鼓励：**高质量短素材负责质感 + Web Audio 负责动态混音、pitch variation、节流、优先级、Voice Budget 与状态响应**。

不要求所有关键声音继续由 sine/triangle/square/noise 纯合成。Phase 1 提供 sample-ready 接口；实际素材在 Phase 2/3 按最终美术与动作节奏接入。

## 8. 验收标准

- 保护期到成长期不能有“突然换了一首歌”的感觉。
- 怪海时玩家仍能识别当前最重要技能、受伤与 Boss 信号。
- 单个声音好听不是最终标准；必须在完整战场上下文中成立。
- 手机外放、普通电脑扬声器、耳机均应保持主要信息可读。
- 用户不需要判断频率或和声，只需反馈：舒服/突兀、爽/软、清楚/混乱、像/不像对应技能。
