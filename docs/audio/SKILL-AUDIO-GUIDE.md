# 《此生为蛇》技能音频规范

版本：v1.1
性质：ChatGPT 与 Codex 共用的技能音频真理源

## 1. 每个技能必须记录

- 主频段；
- 攻击瞬态；
- 能量或材质尾音；
- Lv1、Lv3、Lv5 层次；
- 触发事件；
- 通用 `enemy:hit` 是否参与；
- 同类节流；
- 跨类优先级；
- 手机扬声器可读性。

## 2. 单一主要音效所有者

一个伤害来源在一次攻击中只能有一个主要技能音效所有者。

拥有专属技能音效的来源必须明确决定：

- 专属技能音是否播放；
- 通用 `enemy:hit` 是否静音；
- 击杀音是否额外保留。

禁止同一次攻击无意触发：

```text
通用命中音
+
专属技能音
```

否则同一个等级会听起来像随机切换音色。

## 3. 必须审查完整事件顺序

```text
技能触发
→ hurt/applyDamage
→ enemy:hit
→ 技能专属 fx 事件
→ enemy:dead
```

不能只检查专属 `fx:*` 监听器。

## 4. 节流与优先级

- 每个技能族默认维护独立 gate；
- 不默认让闪电和电磁共用同一个 `lastPlayedAt`；
- 跨类优先级不能导致专属音被取消、但通用命中音仍保留；
- 新一局、重开和相关音频生命周期事件必须重置 gate；
- 高频攻击节流只抑制同类重复，不破坏技能身份。

## 5. 基础技能与 Combo

### 基础闪电

- 高频裂响；
- 锐利击穿瞬态；
- 短促滋滋尾音；
- 轻盈、快速；
- 不叠加通用低沉命中音。

### 电磁炮台

- 低频能量炮击；
- 短促机械或晶体“咔”；
- 紫电余响；
- 有重量和齐射感；
- 近同时触发时可适度压过基础闪电。

两者必须在频段、瞬态和尾音上都不同，不能只改音高。

## 6. 等级与混音

- Lv1 不应弱到被 BGM 吞没；
- Lv5 可增加层次和重量，但不能只提高总音量；
- Combo 应比基础技能更有重量，但不能持续压住所有战斗声；
- 敌人死亡声可以保留为独立语义；
- 大量怪物同时命中时，不逐目标重复播放完整技能音。

## 7. 代码检查

- 专属来源是否从通用命中音排除；
- 是否存在两个事件入口播放同一次攻击；
- 同类 gate 是否独立；
- 重置事件是否清理 gate；
- 配置是否集中；
- Gameplay 与 VFX 文件是否保持边界。

## 8. 实机检查

- 同一级每次攻击音色是否稳定；
- 基础技能与 Combo 是否可盲听区分；
- 桌面扬声器和手机是否都听得清；
- 怪多时是否刺耳、爆音或变成噪音墙；
- 暂停、死亡、重开和后台恢复是否正常。
